🔐 熙熙娛樂城｜隱私權政策

最後更新日期：2026 年 9 月 7 日

本隱私權政策說明「熙熙娛樂城」Discord Bot 在提供服務時可能處理及保存的資料。

1. 可能處理的資料

為了提供 Bot 功能，本服務可能處理或保存：

  • Discord User ID
  • Discord Server ID
  • 遊戲紀錄與統計資料
  • 歡樂豆餘額及虛擬交易紀錄
  • VIP 等級與相關進度
  • 虛擬銀行資料
  • 料理、食材及料理效果資料
  • MMO／冒險相關遊戲資料
  • 虛擬股票及相關遊戲資料
  • 提供 Bot 功能所需的其他設定資料

2. 資料用途

上述資料可能用於：

  • 保存玩家遊戲進度。
  • 計算虛擬貨幣餘額。
  • 提供排行榜與遊戲統計。
  • 提供 VIP、銀行、料理及其他 Bot 功能。
  • 防止濫用、異常操作及程式漏洞利用。
  • 維護及改善本服務。

3. Discord 帳號安全

本服務不會要求使用者提供 Discord 密碼、 Discord Token 或其他帳號登入憑證。

請勿將 Discord Token、密碼或其他敏感登入資訊 提供給任何 Bot 或其他使用者。

4. 資料分享

我們不會以販售使用者個人資料為目的向第三方出售資料。

但在提供部分功能時，可能需要透過 Discord 或其他 提供該功能所必要的服務處理相關資料。

5. 資料保存

部分遊戲及虛擬經濟資料可能在使用本服務期間持續保存， 以維持玩家的餘額、進度及功能狀態。

6. 資料安全

我們會採取合理措施保護服務資料， 但任何網路服務均無法保證絕對安全。

7. 政策更新

本隱私權政策可能因 Bot 功能或服務內容調整而更新。 最新版本將公布於本頁面。
